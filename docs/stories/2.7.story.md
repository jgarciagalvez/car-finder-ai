#### AI Integration [Source: architecture/core-workflows.md lines 144-178]

**AI Chat Workflow**:
1. Frontend sends: `{ context: { view, vehicleId }, conversationHistory, userMessage }`
2. Backend fetches vehicle data if vehicleId provided (for context)
3. AIService builds system prompt with vehicle context
4. AIService calls Gemini API with conversation history
5. Gemini returns markdown-formatted response
6. Backend returns `{ aiResponse: "markdown text" }`
7. Frontend renders markdown response in chat UI

**Key Requirements**:
- Conversation history maintained client-side (not stored in database)
- Supports Polish message generation (prompt must specify language)
- Supports translation (prompt must handle bidirectional translation)
- Responses in Markdown format for rich formatting

**Rate Limiting** [Source: architecture/external-apis.md lines 8]:
- Gemini Free Tier: 15 RPM, 1M TPM, 1,500 RPD
- Implement retry logic in AIService for rate limit errors
- No need for rate limiting in chat (user-initiated, low frequency)

`getVehicleById()`:

```typescript
export async function getVehicleById(id: string): Promise<Vehicle> {
  const response = await fetch(`${API_BASE_URL}/vehicles/${id}`);
  if (!response.ok) {
    if (response.status === 404) throw new Error('Vehicle not found');
    throw new Error('Failed to fetch vehicle');
  }
  return await response.json();
}
```

`sendChatMessage()`:
```typescript
export interface ChatContext {
  view: 'dashboard' | 'detail';
  vehicleId?: string;
}

export interface ChatRequest {
  context: ChatContext;
  conversationHistory: ChatMessage[];
  userMessage: string;
}

export interface ChatResponse {
  aiResponse: string;
}

export async function sendChatMessage(
  context: ChatContext,
  conversationHistory: ChatMessage[],
  userMessage: string
): Promise<ChatResponse> {
  const response = await fetch(`${API_BASE_URL}/ai/chat`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ context, conversationHistory, userMessage }),
  });

  if (!response.ok) {
    if (response.status === 404) throw new Error('Vehicle not found');
    throw new Error('AI chat failed');
  }

  return await response.json();
}
```

- **Error**: `TypeError: Cannot read properties of undefined (reading 'toLocaleString')`
- **Root Cause**: Date fields from API can be undefined but functions didn't handle null case

```typescript
const formatTimestamp = (date: Date | string | undefined): string => {
  if (!date) return 'N/A'; // Safe fallback
  const d = typeof date === 'string' ? new Date(date) : date;
  return d.toLocaleString(...);
};
```
