# Story 3.2: Location - Distance Calculation + Maps Integration

## Status
Done

## Story
**As a** user who is unfamiliar with Poland geography,
**I want** to see driving distance from Wrocław and access maps quickly,
**so that** I can easily assess vehicle accessibility and plan visits.

## Acceptance Criteria
1. **Distance Calculation:**
   - Driving distance in km from Wrocław is calculated for each vehicle
   - Distance is stored in database (new field: `distanceFromWroclaw: number | null`)
   - Distance is displayed in both dashboard cards and detail page
   - Distance is sortable in dashboard (ascending/descending)
   - Distance is filterable in dashboard (e.g., "within 50km", "50-100km", "100km+")

2. **Maps Integration - Dashboard:**
   - Vehicle location (city) is clickable
   - Clicking location opens Google Maps in new tab
   - Maps URL includes vehicle city for navigation

3. **Maps Integration - Detail Page:**
   - Same clickable location as dashboard
   - Interactive Google Maps embed showing vehicle location
   - Map shows city-level pin (no exact address, as not available)
   - Map is appropriately sized and positioned in layout

4. **Distance Calculation for New Vehicles:**
   - When new vehicles are scraped, distance is calculated automatically
   - Existing vehicles without distance are backfilled via migration/script

#### Distance Calculation API Options [Source: external-apis.md]

**Option 1: Google Maps Distance Matrix API** (Recommended if budget allows)
- **Endpoint**: `https://maps.googleapis.com/maps/api/distancematrix/json`
- **Parameters**: `origins=Wrocław,Poland&destinations={city},Poland&key={API_KEY}`
- **Response**: JSON with distance in meters and duration
- **Rate Limits**: Free tier varies, typically low (consider costs for 200-300 vehicles)
- **Pricing**: Pay-as-you-go after free tier

**Option 2: OpenStreetMap OSRM (Free, Open Source)**
- **Endpoint**: `http://router.project-osrm.org/route/v1/driving/{lon1},{lat1};{lon2},{lat2}`
- **Parameters**: Requires geocoding city to lat/lon first (use Nominatim API)
- **Response**: GeoJSON with route distance
- **Rate Limits**: Public instance has rate limits, recommend self-hosting for production
- **Pricing**: Free (open source)

**Option 3: Hybrid Approach** (Recommended for MVP)
- Use Google Maps Distance Matrix API for accuracy
- Cache results aggressively (distance from Wrocław to city X rarely changes)
- Implement in-memory cache in DistanceCalculationService to avoid duplicate API calls
- Store all calculated distances in database for future scrapes of same city

**Implementation Decision**:
- User must decide which API to use during story execution
- CRITICAL: Add `.env` variable for API key (e.g., `GOOGLE_MAPS_API_KEY` or `DISTANCE_API_KEY`)
- Service must handle API failures gracefully (return null, log error)

#### Backfill Script Pattern [Source: backend-architecture.md, apps/api/src/scripts/analyze.ts]

**Script Location**: `apps/api/src/scripts/backfill-distances.ts`

**Script Structure** (similar to analyze.ts):
```typescript
import { VehicleRepository } from '@car-finder/db';
import { DistanceCalculationService } from '../services/DistanceCalculationService';

async function backfillDistances() {
  // Load environment
  // Initialize services
  const vehicleRepo = new VehicleRepository();
  const distanceService = new DistanceCalculationService();

  // Load vehicles without distance
  const vehicles = await vehicleRepo.getAllVehicles();
  const vehiclesWithoutDistance = vehicles.filter(v => v.distanceFromWroclaw === null);

  console.log(`Found ${vehiclesWithoutDistance.length} vehicles without distance`);

  // Process each vehicle
  for (let i = 0; i < vehiclesWithoutDistance.length; i++) {
    const vehicle = vehiclesWithoutDistance[i];
    const city = vehicle.sellerInfo.location?.split(',')[0].trim();

    if (!city) {
      console.log(`Skipping vehicle ${vehicle.id} - no city`);
      continue;
    }

    console.log(`[${i + 1}/${vehiclesWithoutDistance.length}] Calculating distance for ${city}...`);

    const distance = await distanceService.calculateDistanceFromWroclaw(city);

    if (distance !== null) {
      await vehicleRepo.updateVehicle(vehicle.id, { distanceFromWroclaw: distance });
      console.log(`  -> ${distance} km`);
    } else {
      console.log(`  -> Failed to calculate`);
    }

    // Rate limiting delay (e.g., 100ms between requests)
    await new Promise(resolve => setTimeout(resolve, 100));
  }

  console.log('Backfill complete');
}

backfillDistances().catch(console.error);
```

**Script Execution**:
- Add to `apps/api/package.json`: `"backfill-distances": "tsx src/scripts/backfill-distances.ts"`
- Run once after migration: `pnpm --filter @car-finder/api backfill-distances`

```typescript
const sortVehicles = (vehicles: Vehicle[], sortBy: SortOption): Vehicle[] => {
  const sorted = [...vehicles].sort((a, b) => {
    switch (sortBy) {
      // ... existing sort cases ...

      case 'distance-asc':
        // Handle null: sort null values to end
        if (a.distanceFromWroclaw === null) return 1;
        if (b.distanceFromWroclaw === null) return -1;
        return a.distanceFromWroclaw - b.distanceFromWroclaw;

      case 'distance-desc':
        // Handle null: sort null values to end
        if (a.distanceFromWroclaw === null) return 1;
        if (b.distanceFromWroclaw === null) return -1;
        return b.distanceFromWroclaw - a.distanceFromWroclaw;

      default:
        return 0;
    }
  });
  return sorted;
};
```

**Distance Filter State**:
```typescript
interface VehicleState {
  // ... existing state ...
  distanceFilter: 'all' | 'within-50' | '50-100' | '100-plus';
}

// Reducer action
{ type: 'SET_DISTANCE_FILTER', payload: 'within-50' }

// Filter logic in filteredVehicles
const filteredVehicles = useMemo(() => {
  let result = sortVehicles(state.vehicles, state.sortBy);

  // Apply status filter (existing)
  if (state.statusFilter?.length > 0) {
    result = result.filter(v => state.statusFilter!.includes(v.status));
  }

  // Apply distance filter (NEW)
  if (state.distanceFilter !== 'all') {
    result = result.filter(v => {
      if (v.distanceFromWroclaw === null) return false; // Exclude null distances

      switch (state.distanceFilter) {
        case 'within-50':
          return v.distanceFromWroclaw <= 50;
        case '50-100':
          return v.distanceFromWroclaw > 50 && v.distanceFromWroclaw <= 100;
        case '100-plus':
          return v.distanceFromWroclaw > 100;
        default:
          return true;
      }
    });
  }

  return result;
}, [state.vehicles, state.sortBy, state.statusFilter, state.distanceFilter]);
```
