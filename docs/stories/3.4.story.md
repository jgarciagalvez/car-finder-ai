# Story 3.4: Filtering - Hide Not Interested & Deleted Vehicles

## Status
Done

## Story
**As a** user,
**I want** "not interested" vehicles hidden by default with an easy toggle to show them, and "deleted" vehicles completely archived away,
**so that** I can focus on active vehicles while still being able to review hidden ones when needed.

## Acceptance Criteria

### 1. Not Interested Status (Soft Hide)
- **AC1.1**: Dashboard hides vehicles with status="not_interested" by default
- **AC1.2**: UI includes a "Show Not Interested" checkbox toggle (OFF by default)
- **AC1.3**: When toggle ON, not_interested vehicles appear in their normal sorted position with status badge
- **AC1.4**: When toggle OFF, not_interested vehicles are hidden from the list
- **AC1.5**: Toggle state persists during user session (SPA navigation)

### 2. Deleted Status (Hard Archive)
- **AC2.1**: Deleted vehicles are NEVER shown in regular list (no toggle)
- **AC2.2**: Deleted vehicles only visible when explicitly filtering via status dropdown (select "Deleted")
- **AC2.3**: Deleted vehicles appear in sorted order when filtered

### 3. Inline Placeholder Notifications
- **AC3.1**: When user changes status TO "not_interested" (with toggle OFF), show inline placeholder: "Vehicle Added to Not Interested List" with X dismiss button
- **AC3.2**: When user changes status TO "deleted", show inline placeholder: "Vehicle Deleted" with X dismiss button
- **AC3.3**: Placeholders persist in the vehicle's position until manually dismissed (X clicked)
- **AC3.4**: Dismissing placeholder collapses the slot (list reflows)
- **AC3.5**: Placeholders only appear on ACTION (status change), NOT on page load with already-filtered vehicles
- **AC3.6**: If toggle is ON when marking "not_interested", vehicle stays visible (no placeholder needed)
- **AC3.7**: Placeholders are slim/subtle, non-intrusive

### 4. Status Badge Styling
- **AC4.1**: "not_interested" status badge uses red background with red text
- **AC4.2**: Badge appears on image carousel when vehicle is visible

### 5. Filter Integration
- **AC5.1**: "Show Not Interested" toggle works independently from status filter dropdown
- **AC5.2**: Status filter dropdown can explicitly show "deleted" or "not_interested" vehicles
- **AC5.3**: No regression in sorting, distance filter, or other status filters

## Dev Notes

### Behavioral Summary

**Not Interested Flow:**
1. User marks vehicle as "not_interested"
2. If toggle OFF → Vehicle disappears, placeholder appears in slot
3. Placeholder persists until user clicks X
4. X clicked → Slot collapses, list reflows
5. If toggle ON → Vehicle stays visible with red badge, no placeholder

**Deleted Flow:**
1. User marks vehicle as "deleted"
2. Vehicle disappears immediately
3. Placeholder appears: "Vehicle Deleted" with X
4. Placeholder persists until dismissed
5. To view deleted: Select "Deleted" from status filter dropdown

### State Structure

```typescript
interface VehicleState {
  // ... existing fields ...
  showNotInterested: boolean;  // Toggle for not_interested visibility
  recentlyHiddenVehicles: Map<string, 'not_interested' | 'deleted'>;  // Tracks actions
  dismissedPlaceholders: Set<string>;  // Tracks which placeholders user dismissed
}
```

### Placeholder Lifecycle

- **Created**: When status changes TO not_interested (toggle OFF) or TO deleted
- **Persists**: Until user clicks X dismiss button
- **Session-bound**: Survives SPA navigation, clears on page refresh
- **Position**: Occupies the vehicle's slot in the list
- **Collapse**: When dismissed, slot removed and list reflows

### Filter Interaction Matrix

| showNotInterested | statusFilter | Not Interested | Deleted |
|-------------------|--------------|----------------|---------|
| false | null | Hidden | Hidden |
| true | null | Shown | Hidden |
| false | ['not_interested'] | Shown | Hidden |
| true | ['not_interested'] | Shown | Hidden |
| false | ['deleted'] | Hidden | Shown |
| true | ['deleted'] | Hidden | Shown |
| false | ['new'] | Hidden | Hidden |
| true | ['new'] | Hidden | Hidden |

**Key Insight**:
- Not Interested toggle only affects `status === 'not_interested'`
- Deleted NEVER appears unless explicitly filtered via status dropdown
- Status filter dropdown overrides toggle for explicit selections
