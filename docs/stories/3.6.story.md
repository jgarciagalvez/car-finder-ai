### Technical Approach - Client-Side Title Management

Since both pages are client components (`'use client'`), the Next.js static `Metadata` API cannot be used directly in these pages. The recommended approach is:

**Option 1: Direct `document.title` manipulation (RECOMMENDED for this story)**
```typescript
useEffect(() => {
  document.title = "Dashboard | Car Finder AI";
}, []);
```
- Simple, direct, works immediately
- No additional dependencies
- Standard React pattern for client-side title management

**Option 2: Next.js `next/head` component (NOT applicable)**
- Only works with Pages Router, not App Router
- Not compatible with App Router architecture

**Option 3: Server Components with `generateMetadata`**
- Would require refactoring to server components
- Vehicle detail page needs client-side fetching (useEffect, useState)
- Too much refactoring for this simple story
- Not recommended for MVP

### Implementation Pattern

**Dashboard Page:**
```typescript
export default function DashboardPage() {
  // ... existing state

  // Set page title
  useEffect(() => {
    document.title = "Dashboard | Car Finder AI";
  }, []);

  // ... rest of component
}
```

**Vehicle Detail Page:**
```typescript
export default function VehicleDetailPage({ params }: VehicleDetailPageProps) {
  const [vehicle, setVehicle] = useState<Vehicle | null>(null);
  const [isLoading, setIsLoading] = useState(true);

  // Set page title based on vehicle data
  useEffect(() => {
    if (isLoading) {
      document.title = "Loading... | Car Finder AI";
    } else if (vehicle) {
      document.title = `${vehicle.name} | Car Finder AI`;
    } else {
      document.title = "Vehicle Not Found | Car Finder AI";
    }
  }, [vehicle, isLoading]);

  // ... rest of component
}
```

### Cleanup Considerations

The title will automatically reset when navigating to another page with its own title effect. No explicit cleanup needed since:
1. Each page manages its own title
2. Root layout default title ("Car Finder AI") only applies on initial load
3. Navigation triggers new page's title effect
