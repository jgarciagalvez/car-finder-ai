# Story 3.7: Existence Check - Auto-Verification on Detail Page

## Status
Done

## Story
**As a** user,
**I want** vehicles to automatically check if they're still available on Otomoto when I view their details,
**so that** I can identify removed listings without manual effort.

## Acceptance Criteria

### 1. Database Fields
- **AC1.1**: Field `isRemovedFromSource: boolean` exists (added in Story 3.5)
- **AC1.2**: Default value is `false` for all vehicles
- **AC1.3**: New field `lastExistenceCheck: Date | null` tracks when vehicle was last verified
- **AC1.4**: Default value is `null` for new vehicles

### 2. Auto-Check on Detail Page Visit
- **AC2.1**: When user opens vehicle detail page, system checks if verification is needed
- **AC2.2**: Check triggers if: `lastExistenceCheck` is null OR more than 4 hours old
- **AC2.3**: Check skipped if: vehicle was scraped less than 4 hours ago (fresh data)
- **AC2.4**: Check runs in background (non-blocking page load)
- **AC2.5**: On completion, updates `isRemovedFromSource` and `lastExistenceCheck`
- **AC2.6**: If vehicle removed, shows toast notification: "This vehicle has been removed from Otomoto"

### 3. Visual Warning Badge
- **AC3.1**: Vehicles with `isRemovedFromSource = true` display warning badge next to title
- **AC3.2**: Badge shows: `⚠️ Removed from Source`
- **AC3.3**: Badge visible in both dashboard cards and detail view header
- **AC3.4**: Badge styled with orange/yellow warning colors, noticeable but not obstructive
- **AC3.5**: Vehicles remain visible in dashboard (NOT auto-hidden or auto-deleted)
- **AC3.6**: User manually decides to mark as "deleted" status or keep in list

### 4. No Auto-Deletion
- **AC4.1**: Flagging as removed does NOT automatically change vehicle status
- **AC4.2**: User maintains full control over status decisions
- **AC4.3**: Flagged vehicles can still be contacted, visited, etc.
- **AC4.4**: User can mark vehicle as 'deleted' to hide from dashboard (uses Story 3.4 filter)

### 5. API Implementation
- **AC5.1**: Create new API endpoint: `POST /api/vehicles/:id/check-existence`
- **AC5.2**: Endpoint makes HEAD request to vehicle's `sourceUrl`
- **AC5.3**: Returns 404/410 → sets `isRemovedFromSource = true`, updates `lastExistenceCheck`
- **AC5.4**: Returns 200 → sets `isRemovedFromSource = false`, updates `lastExistenceCheck`
- **AC5.5**: Handles errors gracefully (network issues, timeouts) - does not update fields on error
- **AC5.6**: Returns result with `isRemovedFromSource` status and timestamp

### 6. One-Time Cleanup Script (Existing Vehicles)
- **AC6.1**: Create standalone script to check all existing vehicles (~500)
- **AC6.2**: Script runs sequentially with 3s delays between requests
- **AC6.3**: Vehicles returning 404/410 are automatically marked as status = 'deleted'
- **AC6.4**: Updates both `isRemovedFromSource = true` AND `status = 'deleted'`
- **AC6.5**: Script logs progress and summary (e.g., "Checked 500 vehicles. 15 marked as deleted.")
- **AC6.6**: Script is deleted after successful execution (one-time use)

### API Endpoint Pattern

**Follow existing POST endpoint pattern**:
```typescript
// apps/api/src/routes/vehicles.ts
router.post('/:id/check-existence', async (req: Request, res: Response) => {
  try {
    const { id } = req.params;
    const vehicleRepository = await ServiceRegistry.getVehicleRepository();
    const vehicle = await vehicleRepository.findVehicleById(id);

    if (!vehicle) {
      return res.status(404).json({
        error: 'Vehicle not found',
        message: `No vehicle found with ID: ${id}`
      });
    }

    // Make HEAD request to sourceUrl
    const result = await checkVehicleUrl(vehicle.sourceUrl);

    // Update database
    await vehicleRepository.updateVehicle(id, {
      isRemovedFromSource: !result.exists,
      lastExistenceCheck: new Date().toISOString()
    });

    res.status(200).json({
      vehicleId: id,
      isRemovedFromSource: !result.exists,
      lastExistenceCheck: new Date().toISOString(),
      httpStatus: result.status,
      message: result.exists ? 'Vehicle still available' : 'Vehicle removed from Otomoto'
    });
  } catch (error) {
    res.status(500).json({
      error: 'Internal server error',
      message: error instanceof Error ? error.message : 'Check failed'
    });
  }
});
```

### HTTP Request Implementation

**HEAD Request for Existence Check**:
```typescript
async function checkVehicleUrl(sourceUrl: string): Promise<{ exists: boolean; status: number }> {
  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 10000); // 10s timeout

    const response = await fetch(sourceUrl, {
      method: 'HEAD',
      redirect: 'follow',
      signal: controller.signal
    });

    clearTimeout(timeout);

    if (response.status === 404 || response.status === 410) {
      return { exists: false, status: response.status };
    } else {
      return { exists: true, status: response.status };
    }
  } catch (error) {
    // Network error, timeout, etc. - treat as uncertain, don't update
    throw error;
  }
}
```

### Auto-Check Logic (Detail Page)

```typescript
// apps/web/src/app/vehicle/[id]/page.tsx
useEffect(() => {
  const shouldCheck = () => {
    if (!vehicle) return false;

    // Skip if scraped less than 4 hours ago
    const scrapedAt = new Date(vehicle.scrapedAt);
    const hoursSinceScraped = (Date.now() - scrapedAt.getTime()) / (1000 * 60 * 60);
    if (hoursSinceScraped < 4) return false;

    // Check if never checked or checked more than 4 hours ago
    if (!vehicle.lastExistenceCheck) return true;

    const lastCheck = new Date(vehicle.lastExistenceCheck);
    const hoursSinceCheck = (Date.now() - lastCheck.getTime()) / (1000 * 60 * 60);
    return hoursSinceCheck > 4;
  };

  if (shouldCheck()) {
    checkVehicleExistence(vehicle.id)
      .then((result) => {
        setVehicle(prev => ({
          ...prev,
          isRemovedFromSource: result.isRemovedFromSource,
          lastExistenceCheck: result.lastExistenceCheck
        }));

        if (result.isRemovedFromSource) {
          // Show toast notification
          toast.warning('This vehicle has been removed from Otomoto');
        }
      })
      .catch((error) => {
        console.error('Failed to check vehicle existence:', error);
      });
  }
}, [vehicle?.id]);
```

### One-Time Cleanup Script

```javascript
// scripts/check-all-existence.js
const { ServiceRegistry } = require('@car-finder/db');
const { WorkspaceUtils } = require('@car-finder/utils');

async function main() {
  await WorkspaceUtils.loadEnvironment();

  const vehicleRepository = await ServiceRegistry.getVehicleRepository();
  const vehicles = await vehicleRepository.findAllVehicles();

  // Filter: not already removed AND not deleted status
  const toCheck = vehicles.filter(v =>
    !v.isRemovedFromSource && v.status !== 'deleted'
  );

  console.log(`Checking ${toCheck.length} vehicles...`);

  let removedCount = 0;
  let errorCount = 0;

  for (let i = 0; i < toCheck.length; i++) {
    const vehicle = toCheck[i];

    try {
      const response = await fetch(vehicle.sourceUrl, {
        method: 'HEAD',
        redirect: 'follow'
      });

      if (response.status === 404 || response.status === 410) {
        // Mark as deleted
        await vehicleRepository.updateVehicle(vehicle.id, {
          isRemovedFromSource: true,
          status: 'deleted',
          lastExistenceCheck: new Date().toISOString()
        });
        removedCount++;
        console.log(`[${i + 1}/${toCheck.length}] ${vehicle.title} - REMOVED (marked as deleted)`);
      } else {
        // Update lastExistenceCheck only
        await vehicleRepository.updateVehicle(vehicle.id, {
          lastExistenceCheck: new Date().toISOString()
        });
      }
    } catch (error) {
      errorCount++;
      console.error(`[${i + 1}/${toCheck.length}] ${vehicle.title} - ERROR: ${error.message}`);
    }

    // Progress log every 10 vehicles
    if ((i + 1) % 10 === 0) {
      console.log(`Progress: ${i + 1}/${toCheck.length}`);
    }

    // Delay before next request (except last)
    if (i < toCheck.length - 1) {
      await new Promise(resolve => setTimeout(resolve, 1500));
    }
  }

  console.log('\n=== SUMMARY ===');
  console.log(`Total checked: ${toCheck.length}`);
  console.log(`Removed (marked deleted): ${removedCount}`);
  console.log(`Errors: ${errorCount}`);
  console.log(`Still available: ${toCheck.length - removedCount - errorCount}`);
}

main().catch(console.error);
```

### Technical Constraints

- **Framework**: Next.js 14.2 with App Router (client components)
- **Backend**: Express.js 4.18 on Node.js 20.11
- **Database**: LibSQL (SQLite-compatible)
- **TypeScript**: Strict mode enabled
- **No external HTTP libraries**: Use native Node.js `fetch` for HEAD requests
- **Rate Limiting**: 1.5 second delays in cleanup script to avoid blocking
- **4-hour cache**: Auto-check only runs if last check was >4 hours ago
- **No auto-deletion (UI)**: Badge only, user decides on status changes
- **Auto-deletion (Script)**: One-time cleanup marks removed vehicles as 'deleted'

### Edge Cases

1. **Network Errors**: Don't update fields on error, log and continue (script) or skip (UI)
2. **Timeouts**: Use 10 second timeout per request, treat timeout as error
3. **Redirects**: Follow redirects (301/302), check final response status
4. **Fresh Vehicles**: Skip check if scraped <4 hours ago
5. **Recent Check**: Skip check if `lastExistenceCheck` <4 hours ago
6. **Script Interruption**: Can safely re-run script, will skip already-deleted vehicles
