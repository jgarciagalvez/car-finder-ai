## Story
**As a** user,
**I want** the system to verify vehicle availability before running expensive AI operations,
**so that** I don't waste API credits on vehicles that have been removed from Otomoto.

### Existence Check Logic (4-Hour Cache)

**Helper Function Pattern** (for batch scripts):
```typescript
function shouldCheckExistence(vehicle: Vehicle): boolean {
  // Skip if scraped less than 4 hours ago (fresh data)
  const scrapedAt = new Date(vehicle.scrapedAt);
  const hoursSinceScraped = (Date.now() - scrapedAt.getTime()) / (1000 * 60 * 60);
  if (hoursSinceScraped < 4) return false;

  // Check if never checked or checked more than 4 hours ago
  if (!vehicle.lastExistenceCheck) return true;

  const lastCheck = new Date(vehicle.lastExistenceCheck);
  const hoursSinceCheck = (Date.now() - lastCheck.getTime()) / (1000 * 60 * 60);
  return hoursSinceCheck > 4;
}

async function checkVehicleExistence(
  vehicle: Vehicle,
  vehicleRepository: VehicleRepository
): Promise<boolean> {
  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 10000);

    const response = await fetch(vehicle.sourceUrl, {
      method: 'HEAD',
      redirect: 'follow',
      signal: controller.signal
    });

    clearTimeout(timeout);

    const exists = !(response.status === 404 || response.status === 410);

    // Update database
    await vehicleRepository.updateVehicle(vehicle.id, {
      isRemovedFromSource: !exists,
      lastExistenceCheck: new Date().toISOString()
    });

    return exists;
  } catch (error) {
    // Network error - fail open, allow operation to proceed
    console.warn(`⚠️  Existence check failed (network error) - proceeding with operation`);
    return true; // Fail-open for resilience
  }
}
```

```typescript
const shouldCheckExistence = (vehicle: Vehicle): boolean => {
  const scrapedAt = new Date(vehicle.scrapedAt);
  const hoursSinceScraped = (Date.now() - scrapedAt.getTime()) / (1000 * 60 * 60);
  if (hoursSinceScraped < 4) return false;

  if (!vehicle.lastExistenceCheck) return true;

  const lastCheck = new Date(vehicle.lastExistenceCheck);
  const hoursSinceCheck = (Date.now() - lastCheck.getTime()) / (1000 * 60 * 60);
  return hoursSinceCheck > 4;
};

const handleForceTranslate = async () => {
  try {
    // Check existence if needed
    if (shouldCheckExistence(vehicle)) {
      const result = await checkVehicleExistence(vehicle.id);

      // Update local vehicle state
      setVehicle(prev => ({
        ...prev,
        isRemovedFromSource: result.isRemovedFromSource,
        lastExistenceCheck: result.lastExistenceCheck
      }));

      if (result.isRemovedFromSource) {
        // Block operation and show toast
        setToast({
          message: 'Cannot translate - vehicle has been removed from Otomoto',
          type: 'warning'
        });
        return;
      }
    }

    // Proceed with translation
    await translateVehicle(vehicle.id, true);
  } catch (error) {
    console.error('Translation failed:', error);
  }
};
```

### Technical Constraints

- **Framework**: Next.js 14.2 with App Router (client components)
- **Backend**: Express.js 4.18 on Node.js 20.11
- **Database**: LibSQL (SQLite-compatible) with Kysely query builder
- **TypeScript**: Strict mode enabled
- **No external HTTP libraries**: Use native Node.js `fetch` for HEAD requests
- **Rate Limiting**: Existence checks count toward 15 RPM limit in batch operations
- **4-hour cache**: Only check if last check was >4 hours ago
- **Fail-open on errors**: Network errors should NOT block operations (resilience)
- **Toast notifications**: Use existing Toast component from Story 3.7

### Error Handling

**Network Errors** (Batch Scripts):
- Log warning but allow operation to proceed
- Do NOT update `isRemovedFromSource` or `lastExistenceCheck`
- Fail-open for resilience

**Network Errors** (Frontend):
- Show generic error toast
- Allow user to retry operation manually

**HTTP 404/410** (Removed Vehicle):
- Block AI operation
- Update `isRemovedFromSource = true`
- Show specific toast: "Cannot translate/analyze - vehicle has been removed from Otomoto"

**HTTP 5xx Errors**:
- Treat as network error (fail-open)
- Allow operation to proceed

### Edge Cases

1. **Fresh Vehicles**: Skip existence check if scraped <4 hours ago (data is fresh)
2. **Recent Check**: Skip existence check if `lastExistenceCheck` <4 hours ago (cached result)
3. **Network Timeout**: 10 second timeout per request, treat timeout as network error (fail-open)
4. **Batch Interruption**: Safe to re-run scripts, will use cached existence checks
5. **`not_interested` Filter**: Batch analyze now skips these vehicles (consistency with translate)
6. **Force Flag**: `--vehicle-id` with force flag still works (single vehicle operations unchanged)
