# Story 3.9: AI Analysis UX - Full Report Generation & Visual Indicators

## Status
Done

## Story
**As a** user,
**I want** clear visual indicators of analysis completeness and the ability to generate full mechanic reports on-demand,
**so that** I can understand what analysis has been performed and access detailed reports only when needed, saving AI credits.

## Acceptance Criteria

### 1. CLI Behavior
- **AC1.1**: `pnpm analyze` generates virtual mechanic summary only (default behavior)
- **AC1.2**: `pnpm analyze --include-full-report` generates both summary AND full detailed mechanic report
- **AC1.3**: Both commands respect existing `--force` flag behavior
- **AC1.4**: Flag applies to single vehicle (`--vehicle-id`) and batch operations

### 2. Visual Indicators - Vehicle Card
- **AC2.1**: Indicators located next to AI scores section (Personal Fit Score, Market Value, Priority Rating)
- **AC2.2**: Styled as small icon + short text pills, subtle and non-intrusive
- **AC2.3**: Badge variants display correctly:
  - `📊 Summary` - When `virtualMechanicSummary` exists but `aiMechanicReport` is null
  - `📋 Full` - When both `virtualMechanicSummary` AND `aiMechanicReport` exist
  - `⚠️ No Analysis` - When `virtualMechanicSummary` is null (no analysis performed)
- **AC2.4**: Badges appear only when AI Analysis section is visible (at least one AI field populated)

### 3. Vehicle Card Action Buttons (Renamed for Clarity)
- **AC3.1**: Replace current "Analyze" button with **"Quick Analysis"** (purple)
  - Generates summary only
  - Fills missing AI data (sanity check, fit score, summary, market value, priority rating)

```typescript
export async function analyzeVehicle(
  vehicleId: string,
  force: boolean = false,
  includeFullReport: boolean = false
): Promise<Vehicle> {
  const params = new URLSearchParams();
  if (force) params.append('force', 'true');
  if (includeFullReport) params.append('includeFullReport', 'true');

  const url = `/api/vehicles/${vehicleId}/analyze${params.toString() ? '?' + params.toString() : ''}`;
  return apiRequest<Vehicle>(url, { method: 'POST' });
}
```
