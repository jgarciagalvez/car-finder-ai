# Story 4.2: Virtual Mechanic Report Redesign

## Status
Done

## Story
**As a** user,
**I want** a concise, scannable virtual mechanic summary with the option to view detailed analysis,
**so that** I can quickly assess vehicle quality without being overwhelmed by information.

## Acceptance Criteria

1. **Concise Summary (Primary View):**
   - AI prompt redesigned to generate bullet-point summary
   - Summary format follows structure:
     ```
     - This model and engine is known for ___
     - Main issues are ___
     - Based on the description, it seems like ___
     ```
   - Summary limited to 3-5 bullet points for quick scanning
   - Summary displayed prominently on detail page (easily visible without scrolling)

2. **Editable Summary:**
   - User can edit the summary text directly on detail page
   - Edit mode activated by clicking edit icon/button
   - Changes saved to database in new field: `virtualMechanicSummary: string | null`
   - Edited summary persists and overrides AI-generated version
   - Clear indication when summary has been manually edited

3. **Full Detailed Report (Secondary View):**
   - Current detailed report moved to separate tab/collapsible section
   - Labeled as "Full Report" or "Detailed Analysis"
   - Also editable (using existing database field)
   - Can be generated on-demand via AI Assistant if not initially created
   - User can manually add notes or detailed observations

4. **AI Prompt Update:**
   - Update/create prompt file in `packages/ai/src/prompts/` for concise summary
   - Prompt emphasizes brevity, bullet points, and actionable insights
   - Prompt focuses on: model/engine reputation, common issues, description red flags
   - Separate prompt for full detailed report (optional generation)

5. **Database Changes:**
   - Add new field: `virtualMechanicSummary: string | null` (for concise summary)
   - Existing field used for full detailed report
   - Migration to populate summary from existing reports (optional)

6. **Rendering Improvements:**
   - Fix markdown rendering issues (proper spacing, formatting)
   - Bullet points render clearly and are easy to read
   - Mobile-friendly formatting

7. **Analysis Script Update:**
   - By default, only generate concise summary (faster processing)
   - Full report can be skipped during bulk analysis (--skip-full-report flag)
   - Full report can be generated on-demand for individual vehicles

#### AI Prompt Architecture [Source: backend-architecture.md, coding-standards.md]

**AI Prompt Organization**:
- **Location**: All AI prompts stored as markdown files in `packages/ai/src/prompts/`

- **Current Mechanic Prompt**: `packages/ai/src/prompts/mechanic-report.md` generates detailed multi-section report

**Existing Mechanic Report Prompt Structure** [Source: mechanic-report.md]:
```markdown
# Virtual Mechanic's Report

## Agent Role
Experienced automotive mechanic with model-specific knowledge

## Task
Generate comprehensive report with sections:
- Known Model Issues
- Critical Inspection Points
- Red Flags to Watch For
- Maintenance Due at This Mileage
- Overall Assessment
- Recommendation

## Output Format
JSON: { "report": "markdown-formatted report" }
```

**New Summary Prompt Requirements**:
- Much shorter output: 3-5 bullet points total (not 6+ sections)
- Focus on: model reputation, known issues, description red flags
- Output format: Simple markdown bullet list
- Example output:
  ```
  - The 2012 BMW 320i (N20 engine) has a critical timing chain issue that can cause catastrophic failure
  - Main issues: turbocharger wastegate rattle, cooling system leaks, oil leaks (valve cover gasket)
  - Based on the description ("well-maintained, recent service"), verify service records especially timing chain replacement
  ```

**Method Implementation Pattern**:
```typescript
async generateVirtualMechanicSummary(vehicle: Vehicle): Promise<string> {
  // 1. Extract vehicle data
  const vehicleData = this.extractVehicleData(vehicle);

  // 2. Load prompt template
  const prompt = PromptLoader.load('mechanic-summary.md', {
    vehicle: vehicleData
  });

  // 3. Call AI provider with JSON schema
  const response = await this.provider.generateContent(prompt, {
    response_mime_type: 'application/json',
    response_schema: { ... }
  });

  // 4. Parse and validate JSON response
  const result = JSON.parse(response);
  return result.summary;  // Return markdown bullet list
}
```

```typescript
// VehicleDetail.tsx structure (conceptual)
export function VehicleDetail({ vehicle, onVehicleUpdate }) {
  const [isEditingSummary, setIsEditingSummary] = useState(false);
  const [summaryText, setSummaryText] = useState(vehicle.virtualMechanicSummary);
  const [isFullReportExpanded, setIsFullReportExpanded] = useState(false);

  const handleSaveSummary = async () => {
    // Call PATCH /api/vehicles/:id with new summary
    const updated = await updateVehicle(vehicle.id, { virtualMechanicSummary: summaryText });
    onVehicleUpdate(updated);
    setIsEditingSummary(false);
  };

  return (
    <div>
      {/* Summary Section - Prominent, always visible */}
      <section className="mechanic-summary">
        <h3>Virtual Mechanic Summary</h3>
        {isEditingSummary ? (
          <textarea value={summaryText} onChange={e => setSummaryText(e.target.value)} />
          <button onClick={handleSaveSummary}>Save</button>
        ) : (
          <ReactMarkdown>{vehicle.virtualMechanicSummary}</ReactMarkdown>
          <button onClick={() => setIsEditingSummary(true)}>Edit</button>
        )}
      </section>

      {/* Full Report Section - Collapsible, secondary */}
      <section className="mechanic-full-report">
        <button onClick={() => setIsFullReportExpanded(!isFullReportExpanded)}>
          Full Detailed Report {isFullReportExpanded ? '▼' : '▶'}
        </button>
        {isFullReportExpanded && (
          <ReactMarkdown>{vehicle.aiMechanicReport}</ReactMarkdown>
        )}
      </section>
    </div>
  );
}
```

```typescript
async analyzeVehicle(vehicle: Vehicle, options: AnalysisOptions): Promise<void> {
  // ... existing code ...

  // Step: mechanic_summary (NEW - generate concise summary by default)

}
```
