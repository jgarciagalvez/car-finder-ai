# Story 4.3: Features Management - Complete Feature System

## Status
Ready

## Story
**As a** user,
**I want** to manually add or delete vehicle features on the detail page,
**so that** I can capture important features mentioned in descriptions but missing from scraped data.

## Acceptance Criteria

1. **Expand/Collapse Functionality:**
   - Dashboard cards show first 5 features by default
   - Clickable "(+N more)" button expands to show all features
   - Button changes to "Show less" when expanded, collapses back to 5 features
   - Expanded state persists during scrolling within same session
   - Reset to collapsed on page refresh/reload

2. **Features Repositioning (Detail Page):**
   - Features section moved higher in detail page layout
   - Position: Right after name and basic info (year, mileage, location)
   - Same expand/collapse functionality as dashboard (first 5, then expandable)

3. **Manual Feature Addition (Detail Page):**
   - "Add Feature" button visible in features section
   - Clicking opens input field or modal for new feature
   - User enters feature text (e.g., "Air Conditioning", "Leather Seats")
   - Validation: no empty features, reasonable character limit (e.g., 100 chars)
   - New feature added to database (updates features array)
   - New feature immediately visible in list

4. **Manual Feature Deletion (Detail Page):**
   - Each feature has delete icon (visible on hover or always visible)
   - Clicking delete prompts confirmation, then removes feature
   - Changes saved immediately to database
   - Deleted features sync back to dashboard automatically

5. **Database Updates:**
   - Features stored as array in database (existing field, update directly)
   - API endpoint: `PATCH /api/vehicles/:id`
   - Accepts `features` array in request body
   - Returns updated vehicle data

6. **Context Synchronization:**
   - VehicleContext automatically syncs changes between dashboard and detail page
   - Leverages existing `updateVehicle` action in VehicleContext
   - Changes in detail page immediately reflect in dashboard card

7. **UI/UX Considerations:**
   - Clear visual distinction between scraped features and manually added features (optional enhancement)
   - Confirmation dialog for destructive actions (delete feature)
   - Loading states during save operations
   - Error handling and user feedback for failed operations

**Updated Endpoint to Support Features**:
```typescript
// apps/api/src/routes/vehicles.ts (modify existing PATCH handler)
router.patch('/:id', async (req, res) => {
  const { id } = req.params;
  const {
    status,
    personalNotes,
    virtualMechanicSummary,
    aiMechanicReport,
    features  // NEW FIELD
  } = req.body;

  // Validate features if provided
  if (features !== undefined) {
    if (!Array.isArray(features)) {
      return res.status(400).json({ error: 'Features must be an array' });
    }
    if (features.some(f => typeof f !== 'string' || f.trim().length === 0)) {
      return res.status(400).json({ error: 'All features must be non-empty strings' });
    }
    if (features.some(f => f.length > 100)) {
      return res.status(400).json({ error: 'Feature text too long (max 100 chars)' });
    }
  }

  // Update vehicle
  const updatedVehicle = await vehicleRepo.update(id, {
    status,
    personalNotes,
    virtualMechanicSummary,
    aiMechanicReport,
    features  // Pass features to repository
  });

  res.json(updatedVehicle);
});
```

**VehicleCard - Expand/Collapse** (AC: 1):
```typescript
// apps/web/src/components/VehicleCard.tsx (modify existing features section)
const [isFeaturesExpanded, setIsFeaturesExpanded] = useState(false);

// Features display logic
const displayedFeatures = isFeaturesExpanded
  ? localVehicle.features
  : localVehicle.features.slice(0, 5);

const hasMoreFeatures = localVehicle.features.length > 5;

return (
  <div className="flex flex-wrap gap-2">
    {displayedFeatures.map((feature, index) => (
      <span key={index} className="bg-orange-100 text-orange-800 px-2 py-1 rounded text-xs">
        {feature.replace(/_/g, ' ').replace(/\b\w/g, l => l.toUpperCase())}
      </span>
    ))}
    {hasMoreFeatures && (
      <button
        onClick={() => setIsFeaturesExpanded(!isFeaturesExpanded)}
        className="bg-gray-100 text-gray-600 px-2 py-1 rounded text-xs hover:bg-gray-200"
      >
        {isFeaturesExpanded
          ? 'Show less'
          : `+${localVehicle.features.length - 5} more`
        }
      </button>
    )}
  </div>
);
```

**VehicleDetail - Feature Management** (AC: 2, 3, 4):
```typescript
// apps/web/src/components/VehicleDetail.tsx (new features management section)
const [features, setFeatures] = useState(vehicle.features || []);
const [isFeaturesExpanded, setIsFeaturesExpanded] = useState(false);
const [isAddingFeature, setIsAddingFeature] = useState(false);
const [newFeatureText, setNewFeatureText] = useState('');

const handleAddFeature = async () => {
  if (!newFeatureText.trim() || newFeatureText.length > 100) return;

  const updatedFeatures = [...features, newFeatureText.trim()];
  setFeatures(updatedFeatures);

  try {
    const updated = await updateVehicle(vehicle.id, { features: updatedFeatures });
    onVehicleUpdate?.(updated);
    setNewFeatureText('');
    setIsAddingFeature(false);
  } catch (error) {
    console.error('Failed to add feature:', error);
    // Revert on error
    setFeatures(features);
  }
};

const handleDeleteFeature = async (index: number) => {
  const updatedFeatures = features.filter((_, i) => i !== index);
  setFeatures(updatedFeatures);

  try {
    const updated = await updateVehicle(vehicle.id, { features: updatedFeatures });
    onVehicleUpdate?.(updated);
  } catch (error) {
    console.error('Failed to delete feature:', error);
    setFeatures(features);
  }
};

return (
  <section className="features-section">
    <h3>Features</h3>

    {/* Feature list with delete icons */}
    <div className="flex flex-wrap gap-2">
      {displayedFeatures.map((feature, index) => (
        <div key={index} className="feature-badge group relative">
          <span>{feature}</span>
          <button
            className="delete-icon hidden group-hover:inline"
            onClick={() => handleDeleteFeature(index)}
            aria-label="Delete feature"
          >
            ×
          </button>
        </div>
      ))}
    </div>

    {/* Add feature button */}
    <button onClick={() => setIsAddingFeature(true)}>Add Feature</button>

    {isAddingFeature && (
      <div>
        <input
          value={newFeatureText}
          onChange={e => setNewFeatureText(e.target.value)}
          placeholder="Enter feature name"
          maxLength={100}
        />
        <button onClick={handleAddFeature}>Save</button>
        <button onClick={() => { setIsAddingFeature(false); setNewFeatureText(''); }}>Cancel</button>
      </div>
    )}
  </section>
);
```
