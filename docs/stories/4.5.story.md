# Story 4.5: Manual Overrides & Priority Flags

## Status
Ready

## Story
**As a** user,
**I want** to manually override AI scores and flag special vehicle features,
**so that** I can correct AI misjudgments and prioritize vehicles with specific characteristics (like tailgate).

## Acceptance Criteria

1. **Editable Priority Score:**
   - Edit existing field: `aiPriorityRating` (0-10 scale)
   - **Dashboard card:** Small edit icon (🖊️) next to Priority Rating
   - **Detail page sidebar:** "Edit" button/link next to Priority Rating
   - Click edit → inline number input (0-10 validation)
   - Save on blur, Enter key, or small save icon (✓)
   - Cancel on Escape key or small cancel icon (✗)
   - Only one field editable at a time per card (prevents multi-edit)
   - Updates `aiPriorityRating` field directly
   - Changes sync immediately between dashboard and detail page (via VehicleContext)
   - **Risk (documented in technical debt):** Re-running AI analysis will overwrite manual edits

2. **Editable Market Value:**
   - Edit existing field: `marketValueScore` (format: "+10%", "-5%", "market_avg", etc.)
   - **Dashboard card:** Small edit icon (🖊️) next to Market Value
   - **Detail page sidebar:** "Edit" button next to Market Value
   - Click edit → inline text input (free text, user can enter any value)
   - Save on blur, Enter key, or small save icon (✓)
   - Cancel on Escape key or small cancel icon (✗)
   - Only one field editable at a time per card (prevents multi-edit)
   - Updates `marketValueScore` field directly
   - Changes sync immediately between dashboard and detail page (via VehicleContext)
   - **Risk (documented in technical debt):** Re-running AI analysis will overwrite manual edits

3. **Tailgate Flag:**
   - Add database field: `hasTailgate: boolean` (default: false)
   - **Dashboard card:** Toggle switch or checkbox always visible (high-frequency action)
   - **Dashboard card:** Visual indicator when checked (e.g., "🚐 Tailgate" badge + checked toggle)
   - **Detail page sidebar:** Toggle switch "Has Tailgate ☐/☑"
   - Toggle immediately saves to database (one-click operation)
   - Clear visual feedback when toggled (brief success indicator)
   - Changes sync immediately between dashboard and detail page

4. **Enhanced Sorting Logic:**
   - Primary sort: Tailgate vehicles first (`hasTailgate = true`), then non-tailgate
   - Secondary sort within each group: By `aiPriorityRating` (may be manually edited)
   - Tertiary sort: User's selected sort criteria (price, year, mileage, etc.)
   - Example: User sorts by "Price Low→High" with tailgate priority:
     1. All tailgate vehicles sorted by price (low to high)
     2. All non-tailgate vehicles sorted by price (low to high)
   - Sorting persists during session
   - Works with all existing sort options

5. **Database Updates:**
   - Add one new field to Vehicle type and database schema:
     - `hasTailgate: boolean` (default: false)
   - Database migration required for tailgate field
   - API endpoints: `PATCH /api/vehicles/:id` (update `aiPriorityRating`, `marketValueScore`, `hasTailgate`)
   - Validation: Priority 0-10, market value free text

6. **Context Synchronization:**
   - VehicleContext syncs manual overrides between dashboard and detail page
   - Changes in detail page immediately reflect in dashboard (and vice versa)
   - Leverages existing `UPDATE_VEHICLE` action
   - Sorting updates automatically when tailgate flag changes

7. **UI/UX Considerations:**
   - Edit icons use consistent styling (small pencil icon 🖊️)
   - Save/cancel icons are small and inline (✓ and ✗)
   - Only one field editable at a time per card (prevents confusion)
   - Inline editing feels smooth (no jarring modals, save-on-blur pattern)
   - Cards may expand slightly when editing (acceptable for UX)
   - Clear success feedback when values saved (brief checkmark or indicator)
   - Validation errors displayed inline (e.g., "Priority must be 0-10")
   - Loading states during save operations (subtle spinner or opacity)
   - Accessible keyboard navigation (Tab, Enter, Escape)

#### Known Risks & Technical Debt [Source: Epic 4 Story 4.5]

**Risk: Manual Edits Overwritten by AI Re-Analysis**
- Re-running AI analysis will overwrite manual edits to `aiPriorityRating` and `marketValueScore`
- No audit trail of which values were manually edited vs AI-generated
- **Mitigation for MVP:** Document this risk in user-facing UI (tooltip or help text)
- **Future Enhancement:** Separate manual override fields to preserve AI original values (e.g., `manualPriorityRating`, `aiPriorityRatingOriginal`)

**Technical Debt Items:**
- No "lock from re-analysis" flag to protect manual edits
- No history/audit log of score changes
- Tailgate flag not auto-detected (manual flagging only)
- No bulk tailgate flagging (must edit vehicles one at a time)
